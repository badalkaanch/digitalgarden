| Aspect                | Details                                                                    |
| --------------------- | -------------------------------------------------------------------------- |
| Location              | Sir Creek, 96 km tidal estuary in Rann of Kutch (Gujarat–Sindh border)     |
| Dispute Type          | Land and Maritime Boundary Dispute                                         |
| India’s Claim         | *[[Thalweg Principle\|Thalweg Principle]]* — boundary should follow deepest navigable channel |
| Pakistan’s Claim      | Entire creek up to eastern bank based on 1914 map resolution               |
| Claim Lines           | - **Green Line**: Pakistan’s claim (entire creek)                          |
|                       | - **Red Line**: India’s claim (thalweg-based, mid-creek)                   |
| Current Control       | De facto under Indian administrative control                               |
| Strategic Importance  | Affects EEZ demarcation and access to oil, gas, and fisheries              |
| International Law     | Governed by UNCLOS (both are signatories)                                  |
| Associated Treaty     | Indus Waters Treaty (suspended by India in 2025)                           |
| Present Status (2025) | No formal resolution; tensions escalated post-Pahalgam attack              |
